# BOAT_PROJECT
This contains the code used in the testing completed in Pensitone at 200m intrvals from 200m to 1km and the code that utilises the limit switch in the stepper motor calibration.


This repo also now contains the python code uploaded to the Pi5 in order to place bounding boxes around objects and give a confidence level. In addition, theres a .ino file of the new code used on the water sampling system that utilises the physical hard stop.
